4.3 Security incidents: the Provider notifies the Customer without undue delay

## 5. Data subject rights and assistance

5.1 The Provider assists the Customer, by appropriate technical and
organisational measures, in responding to requests to access, rectify, erase,
restrict, port or object, taking into account the nature of processing.

5.2 Shipped mechanics: account erasure pseudonymises the user and removes
credentials, sessions, links, settings, seats and queued mail
(`POST /api/v1/account/erasure`); team admins can place run holds to preserve
evidence; retention sidecars remove expired collaboration events, audit rows and
identity tokens when deployed and monitored. Deletion does not reach backups
until they expire.

5.3 The Provider does not respond to a Data Subject directly on the Customer's
behalf unless instructed.

the Provider's compliance with this agreement on [NOTICE] notice, during
business hours, under confidentiality, or accept a written questionnaire in
place of an on-site audit. **[COUNSEL: scope and cost allocation.]**

7.2 At termination the Provider returns or deletes Customer Data within [30]

## Annex A — Processing details

| Item | Detail |
|---|---|
| Data subjects | Customer personnel and contractors with accounts; people named in code, commits, tasks, reviews or meeting transcripts |
| Personal data | Name, email, account identifiers, session metadata, IP-derived security events; authored text (tasks, plans, comments, reviews, meeting transcripts); repo content and metadata; cost/token records; audit trail |
| Special categories | Not intended. The pilot excludes regulated data and production secrets. Accidental inclusion is possible in free-text fields |
| Purpose | Providing the pilot Services: planning, execution, review, collaboration, audit and spend metering |
| Duration | Pilot term plus the retention windows below |
| Retention (shipped defaults) | Collaboration events 30 days, agent events 30 days, audit 365 days, notification outbox 30 days, expired tokens swept by the retention sidecar; backups per `docs/runbooks/backup-and-pitr.md`. Retention runners are opt-in and must be enabled and monitored |
| Model calls | Prompts and selected code context are sent to the model provider chosen by the Customer; provider retention/training terms govern that copy |

## Annex B — Security measures (as shipped)

| Area | Measure | Honest limitation |
|---|---|---|
| Authentication | Passwordless OTP; OIDC SSO with PKCE, nonce and JWKS validation; sessions expire | SSO is a Team-tier feature; a hosted customer IdP has not been drilled |
| Authorisation | Team-scoped roles (admin/engineer/viewer/guest), server-side ownership checks, no-oracle 404s | — |
| Isolation of agent work | Per-run workspace, human plan approval before execution, OS confinement (Seatbelt on macOS, Landlock on Linux), per-task container boundary | macOS Docker Desktop cannot enforce Landlock writes on virtiofs; native Linux is the supported container path |
| Sandbox reads | Landlock read allow-list; forbidden paths omitted; sibling workspaces unreadable | Host/kernel dependent; fixed a bootstrap bug on 2026-10-25 that had granted `/` for `/bin/sh` |
| Secrets | App-level encryption of provider keys, GitHub tokens and SSO secrets under a master key; API responses return hints only | A stolen master key decrypts them; backups contain the ciphertext |
| Audit | Append-only hash-chained audit rows; run holds preserve evidence | Retention is opt-in |
| Transport | HTTPS termination at the operator edge; internal compose network | Operator must provide the certificate and proxy configuration |
| Backups | Base backups + WAL archiving; drills executed against S3-compatible storage (2026-10-25) | Not encrypted by the app; object-store encryption is required |
| Egress | Sandbox network off by default; opt-in allow-list CONNECT proxy | Not exercised against a live Docker daemon in the shipped compose |
| Billing | Stripe adapter exists; routes stay unmounted without a key | Stripe is unavailable in Pakistan; billing remains flag-off |
