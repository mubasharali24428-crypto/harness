## Additional fixes landed in this pass

- Tenant scoping for every Section 6 meeting route (unknown and foreign ids both
  404, no existence oracle); AI key lookup requires the caller's team; no global
  key fallback.
- Section 1 session revocation on member removal; missing membership answers 401
  (not 500).
- Section 4 `propose_plan` requires `projectId`, verifies project/run ownership,
  and the auth dependency is actually applied (the old default-argument form
  skipped it).
- Section 8 review evidence: blank diffs refused; request-supplied diff disabled
  by default (`HARNESS_ALLOW_REQUEST_DIFF`); GitHub reads use the authenticated
  reviewer, never a system identity; model summaries receive the team id.
- Section 5 confinement: no silent `off`; `off` requires
  `HARNESS_SANDBOX_ALLOW_UNCONFINED=1`; `auto` fails closed with no usable OS
  boundary; `DockerSandboxRunner` raises instead of silently executing on the host.
- Section 6 durable meetings: migration `0061_meeting_durable_state.sql` persists
  meeting closure, messages, briefs, summaries, and prompt history; the durable
  service path is covered by `test_meeting_state_round_trips_after_service_rebuild`.
- Section 3 cost attribution: model calls accept an optional owned `runId`, usage
  records retain it, and `/spend` reports explicit unattributed usage instead of
  silently folding it into a team total.
- Pilot/legal artifacts: pricing, terms, privacy, and the SOW/DPA checklist now
  identify the commercial and counsel-review gates; they are drafts, not offers.

   until Linux read confinement is implemented and tested.
2. **Docker runner:** `DockerSandboxRunner` is deliberately unimplemented. The
   Compose journey passed only with the explicit diagnostic unconfined opt-out;
   that is not sandbox security evidence.
3. **Real-provider smoke:** never run with a real engine key; still a pilot gate.
4. **Legal/pricing:** counsel review, licence decision, payment rail, retention,
   subprocessors, and liability terms remain unresolved.
5. **Host certification:** the managed agent sandbox cannot independently certify
   host Seatbelt availability without elevated host permissions; the final
   escalated gate was green, but this is not a production-host certification.
