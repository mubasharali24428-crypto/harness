## Context
The register gives members a request path to admin without granting invitation or implicit access authority.

## Options
1. **Keep the default in force (recommended):** requests go to admin; no implicit access or invitation authority.
2. Let members invite directly — faster onboarding, but bypasses the admin gate.
3. Let members message each other only — narrower, but leaves no request path to admin.

## Consequences of the default
Unchanged from the register default; no code path is enabled by this draft.
