## 4. Model-backed benchmark via TokenLab (2026-11-13, cap $1.00)

`code-search` (non-held-out), 5 trials, on `harness-rc` switched to `ENGINE_LIVE_MODE=live`,
`DEEPSEEK_BASE_URL=https://api.tokenlab.amd.com/v1`, `DSH_MODEL=DeepSeek-V4-Flash` (the RC orchestrator and
worker-daemon were recreated with only those env values changed; the key is in the shell/containers, never a file
here). Result: **5/5 PASS**, wall p50 65 s / p95 117 s, 3–7 tool calls, ledger cost 0.0146 USD per task,
**0.073 USD total by the ledger, 0.0028 true per the website** (cap 1.00). Evidence: `docs/briefs/evidence/w7-bench/live-model/`.

- **Cost calibration against the Token Lab website (2026-11-13 14:18):** the site shows 31 requests, 157.2k tokens and
  0.002769 points used (of 10). The ledger's tokens match exactly (155,013 in + 2,187 out = 157,200), so metering is right;
  its dollars were wrong, 0.0808 USD, about 29x too high. Cause: `DeepSeek-V4-Flash` had no rate-card entry, so the ledger used its
  fallback of 0.50 in / 1.50 out USD per M tokens (fitted from the rows). Measured blended rate: 0.002769 / 157,200 tokens =
  0.0176 USD per M tokens (98.6% of tokens were input, with a large repeated prompt prefix, so this is an input-heavy,
  likely cache-discounted rate; the site does not split input and output). Added `"DeepSeek-V4-Flash": {"input": 0.0176, "output": 0.0176}`
  to the rate card in `.env` and `deploy/.env` (gitignored) and reloaded the RC orchestrator; at that rate the same tokens price
  to 0.002767. Valid for agent-style input-heavy runs; an output-heavy workload would be under-priced. The 6 `cost_ledger` rows in the RC (scratch) database were re-priced
  in one transaction (sum 0.002767 vs the site's 0.002769; old values 0.007832, 0.019522, 0.010552, 0.018652, 0.013580, 0.010649),
  the 5 attempt files now carry the corrected `costUsd` (old value kept as `costUsdFallbackPriced`) and the stats read
  `cost/task=0.0005`; true cost of the 5 trials was about 0.0021 (so the "0.073" earlier in this section is the fallback figure). My earlier "0.10/0.50 per M" reading of a 13-token curl cost was wrong (small uncached call).
- The spend cap held with wide margin: conservative accounting 0.25, ledger 0.073, true 0.0028 of the 1.00 cap.
