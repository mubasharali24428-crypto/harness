## T1 — Leaked provider key

Inject: a canary key string appears in a public GitHub issue pasted by a
design partner ("this showed up in our export").

Walk: incident-response.md §2 S1 → preserve evidence (export + audit rows) →
rotate the key via the keys API → grep every export path for the canary
(the P4 sweep command) → notify the team.

downloaded by the UI; the store volume holds artifacts, not exports).

volume + `deploy/backup/store-backup.sh` output as the evidence location.
Residual: none blocking; P4's redaction sweep is the detection control.
