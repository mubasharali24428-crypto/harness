## Regression found and fixed by the re-drill (the prompt's "re-probe before you rely on it" earning its keep)

the Linux bootstrap for EVERY command (all commands died with a Python syntax
error in the bootstrap). macOS tests could not see it (Seatbelt path). The
in-image re-probe caught it; bootstrap rebuilt and re-verified (compiles;
control executes; denies hold). Lesson recorded: any edit to the bootstrap
string must be followed by a Landlock-path probe on Linux, not just the macOS
suite.
