## What a user can now do that they could not before

- Open **/preview/run**, **/preview/diff** and **/preview/review** and see the new
  three-pane look on the **real seeded demo run** (same API clients as the live
  pages: `listRuns`, `getRunAggregate`, `getPlan`, `getReviewData`; demo seed via
  `seedDemo` from the empty state):
  - sidebar run list grouped **Needs you / Working / Done**, per project, with a
    project switcher; rows are titled by the run's **goal** (from its plan), with
    state dot and age — never an id;
  - the run as **one scrolling column of step blocks**: one line when collapsed
    (verb, target, time), opening to a short receipt (when / duration / cost —
    "not recorded per step" when the backend has none);
  - the plan as plain steps (no JSON), and the **verdict card** at the end of a
    finished run;
  - **/preview/diff** adds the right **Diff pane** (per-file unified diff from the
    review service, add/del tints, line numbers);
  - **/preview/review** puts the **verdict card above the diff** in that pane.
- The four designed states are reachable through **real conditions** on every route:
  - loading (skeleton immediately), signed-out visit (sign-in state with a return
    link), no runs yet (empty state whose action seeds the demo run), a run id that
    does not exist (`/preview/run?run=does-not-exist-xyz` → "Run not found" +
    retry), unknown facts in words ("not recorded", "unknown").
- Money everywhere follows the R1 rule: **two decimals from one cent up,
  "< $0.01" below, "unknown" when not recorded** — the verdict card no longer
  prints `$0.000057` (it now says `< $0.01`), the run header says `Spend < $0.01`.
- The old shell chrome is gone app-wide: body **grid background**, the fake
  **window dots**, the **clock**, and the status bar are removed (AppShell + CSS);
  the preview routes also have **no breadcrumb / banner stack**.

## Left out / not verified / backend gaps

- **Not verified on the RC frontend image yet.** The brief requires the owner's
  go-ahead before rebuilding `harness-rc-frontend-1`; that rebuild is the one
  remaining step to repeat the checks on `http://localhost:3011`. Command ready:
  `cd deploy && HARNESS_IMAGE_TAG=<new tag> docker compose -p harness-rc --env-file ../.env -f docker-compose.yml -f docker-compose.rc.yml build frontend && docker compose -p harness-rc --env-file ../.env -f docker-compose.yml -f docker-compose.rc.yml up -d --no-deps --no-build frontend`.
- **Per-step cost is not recorded** by the backend (aggregate steps carry no cost),
  so collapsed blocks show duration only and the receipt says "not recorded per
  step". No endpoint gap invented around it.
- **Run titles come from the run's plan** (`getPlan`), fetched per visible run;
  a run with no plan yet reads "Untitled run". A `goal` field on the runs list
  would remove N−1 plan calls (backend gap, report only).
- "Since last iteration" on the diff is a static sentence for now (the review
  service records one diff per PR); the toggle arrives with R4's iteration data.
- Sidebar "Old workspace" / "Review" footer links are temporary R1 affordances
  so nothing is lost before R2 rebuilds the shell.
- No components deleted; `titlebar`/`statusbar` markup+CSS and the clock effect
  were removed from `AppShell.tsx` (the mobile top bar/drawer stay untouched).
