Phase **R2** of `docs/briefs/ui-master-prompt-2026-11-14.md`. Branch `w28-s1-delegate`, nothing pushed.
The owner approved the R1 look in the session that built this.

## What a user can now do

- On every signed-in page the sidebar is the **run list** for the selected project, grouped
  Needs you / Working / Done. Rows are titled by the run's goal, show the action a person owes
  ("Review the pull request") or the state, and the age. The open run's row is marked current.
- The old nav destinations moved to a **Menu** in the sidebar footer (All runs, Meeting, Cost,
  Settings, Get started) and stay in the command palette. "New run" opens the start screen.
- The run page is **one centre column** (goal as title, state, spend, estimate, Pause/Resume, step
  blocks, plan, verdict) with **one closable right pane**: Diff, Plan, Terminal, Evidence, Advanced.
  The five tabs are gone.
- The pane is in the URL (`?pane=`), so reload, shared links and back/forward land on the same view.
- Old links still land: `?tab=changes|plan|working|team` opens the matching pane, the demo landing
  (`?tab=changes&demo=1`) opens the diff with the REPLAY label, `/preview/*` redirects to `/`.

## Where each former tab's content lives (all one click from the run)

| Was | Now |
|---|---|
| Overview: state, cost, PR link, Pause/Resume | Run header |
| Overview: event timeline, exact cost, run id, delegated-children review | Evidence pane |
| Plan & work: plan gate, plan/work history | Plan pane |
| Team: shared run panel | Advanced pane |
| Working: working area, scope request | Terminal pane |
| Changes: verdict + PR diff, checkpoint revert/restore | Diff pane |
| Breadcrumb links (project tree), checkpoints | Links at the foot of the Evidence pane |
