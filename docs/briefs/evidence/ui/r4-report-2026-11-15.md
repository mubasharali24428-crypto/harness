Phase **R4** of `docs/briefs/ui-master-prompt-2026-11-14.md`. Branch `w28-s1-delegate`, nothing pushed.

## What a user can now do

- **Decide the review inside the run.** The Diff pane now has "Your decision" between the verdict
  facts and the diff: Approve, or Request changes with a required note. Both are the review
  service's existing calls. Merging still happens on GitHub, by a person.
- **A risky change needs an explicit tick.** When the pull request has risk flags (or touches
  `auth/`, `payment/`, migrations, `.env`, secrets), the flags are listed and Approve stays disabled
  until "I have read the risk flags above" is ticked. The reason is on screen.
- **Comment on a file.** Each file has "Comment on this file" (optional line number). The comment is
  recorded on the review; while the run is live it is also sent to the agent as direction
  (`path:line: text`), and the pane says when it takes effect. On a finished run it says the comment
  was not sent.
- **Mark files reviewed.** A tick per file hides its diff and counts "n of m files marked reviewed".
- Viewers see the facts, risks and diff, not the decision controls.
- Everything works from the keyboard.
