## What a user can now do (Evidence pane of a run)

- **Read the run's cost as one number**: metered spend in large type, with the plan estimate beside
  it. A run with no recorded spend says "Not metered yet", never $0.
- **Read a trace**: every timed event as a row with a bar placed by its own timestamp. A bar is the
  time until the next recorded event, unless the server measured the step itself (marked
  "measured"). Events with no recorded time are counted and left out.
- **Export the run history**: one button requests the orchestrator's existing `run_history` export,
  waits for it, and downloads the JSON file.
