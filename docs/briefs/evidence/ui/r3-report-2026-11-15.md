## What a user can now do

- **Start a run from one input.** The home screen (`/`) is a composer: type a goal, Enter proposes a
  plan and opens the new run. Nothing runs before the plan is approved. "Start with a screenshot"
  keeps the old plan-gate card one click away.
- **Read and decide the plan without leaving the run.** The plan is pinned above the composer:
  Approve, Edit (goal, steps, tests; saved as a new plan version), Reject, then Start.
  Viewers see the plan but not the buttons.
- **Steer a live run from the same input.** Text is sent to the agent as direction and the reply says
  when it takes effect or that it is queued. `/pause`, `/resume`, `/stop` run the existing controls;
  a command that does not apply to the run's state says why. `@` completes file references.
- **Answer approvals in the column.** Pending approvals show inline with Approve / Reject.
- **See one next step.** Below the run: one question and one button for what the person owes.
- Before approval and after the run ends the composer is disabled and says why.
