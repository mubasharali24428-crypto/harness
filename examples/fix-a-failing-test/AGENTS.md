# Conventions for this kata

- Run `python3 -m pytest -q` before proposing a merge; paste the summary in the plan.
- Fix the implementation, not the expectation: `test_calc.py` describes the
  behaviour we want and must not be edited. The bug is in `increment`.
- Keep the diff to `calc.py`; no renames, no packaging changes.
- A merge needs a human approval — never merge from the run.
